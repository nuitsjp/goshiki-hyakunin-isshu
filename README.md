# 五色百人一首 決まり字クイズ

五色百人一首（青・ピンク・黄・緑・オレンジ）の決まり字を覚えるための学習Webアプリケーションです。

## 概要

このアプリは、五色百人一首の各色（20首ずつ）の問題を4択クイズ形式で出題します。特に「決まり字」を効率よく覚えることに重点を置いており、ヒント機能や統計情報を活用して学習の進捗を管理できます。

## 主な機能

### 1. 色別クイズコース
5つの色（青・ピンク・黄・緑・オレンジ）から学習したい色を選んでスタートできます。各色20首が出題されます。

### 2. 柔軟な出題設定
自分のレベルに合わせて、以下の設定を変更できます。
- **読み札**: 「上の句」または「下の句」のどちらを読み上げるか選択できます。
- **ヒント**: 「決まり字」「初句」「上の句」から初期表示するヒントの種類を選べます。
- **表示モード**: 問題文を「よみがな」または「漢字」で表示できます。
- **出題数**: 5問、10問、20問（全問）から選択可能です。

### 3. クイズ画面
- **4択問題**: 正しい下の句（または上の句）を選びます。
- **ヒント機能**: ボタンをクリックしてヒントの表示方法を切り替えられます。
- **パス機能**: 分からない場合は「パス」して次の問題へ進めます。
- **即時フィードバック**: 正解・不正解をすぐに判定し、正解の読みを表示します。

### 4. 統計・履歴機能
- **学習記録**: 色ごとのプレイ回数、正答率、ヒント利用率を自動で記録します。
- **詳細分析**: 各色ごとの・決まり字別の正答状況や、最近の正答率の推移を確認できます。
- **履歴管理**: 過去のクイズ結果（セッション履歴）を振り返ることができます。

## 使い方

1. **トップ画面**で学習したい「色」を選びます。必要に応じて、上部の設定バーで出題オプションを変更してください。
2. **クイズ画面**で、表示された「決まり字」に対応する正しい札を選んで回答します。
3. 全問終了すると**結果画面**が表示され、正答数と正答率が確認できます。「統計を見る」から詳細な学習記録へアクセスすることも可能です。
